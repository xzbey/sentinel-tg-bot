# Sentinel-2 Telegram Bot 🌍🛰️

Бот для Telegram, который по названию местоположения находит и присылает актуальный спутниковый снимок Sentinel-2 L2A (естественные цвета RGB). Автоматически выбирает наименее облачное изображение за указанный период.

**Бот в Telegram:** [@sentinel2_geo_bot](https://t.me/sentinel2_geo_bot)

## Возможности

- Поиск по названию локации или координатам точки через OpenStreetMap Nominatim (геокодирование).
- Интерактивный диалог: указание радиуса зоны (0.5–50 км) и временного интервала.
- Автоматический выбор снимка с минимальной облачностью (просмотр до 200 снимков за период).
- Получение снимка в формате PNG с разрешением до 10 м/пиксель.
- Подпись к снимку содержит: дату, облачность, координаты, ID снимка и размер.
- Защита от ошибок: валидация ввода, обработка сбоев API, автоперезапуск на сервере.

## Как это работает

1. Пользователь отправляет боту название места (город, парк, улицу).
2. Бот запрашивает радиус (км) и временной интервал (ГГГГ-ММ-ДД ГГГГ-ММ-ДД).
3. Координаты преобразуются в bbox (WGS84) с учётом широтной поправки.
4. Sentinel Hub Catalog API ищет снимки Sentinel-2 L2A в этом bbox и интервале.
5. Из найденных выбирается один с наименьшей облачностью.
6. Sentinel Hub Process API запрашивает RGB-изображение (каналы B04/B03/B02).
7. Бот отправляет фото и метаданные пользователю.

## Технологии

- Python 3.12
- `sentinelhub` (v3.11.5) – работа с Catalog API и Process API Sentinel Hub
- `geopy` (v2.4.1) – геокодирование через Nominatim (OSM)
- `python-telegram-bot` (v22.6) – диалоговый интерфейс
- `Pillow` – постобработка изображений (увеличение яркости)
- `python-dotenv` (v1.2.2) – управление переменными окружения

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone https://github.com/xzbye/sentinel-tg-bot.git
cd sentinel-tg-bot
```

2. Создать виртуальное окружение и установить зависимости:
```bash
apt install python3.12-venv –y

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. Создать файл `.env` в корне проекта и добавить ключи:
```env
BOT_TOKEN=ваш_токен_telegram
SH_CLIENT_ID=ваш_client_id_sentinel_hub
SH_CLIENT_SECRET=ваш_client_secret_sentinel_hub
```

4. Запустить бота:
```bash
python bot.py
```

## Развёртывание на сервере

Проект настроен для работы на VPS (Ubuntu 24.04) через `systemd`. Пример юнита:

```ini
[Unit]
Description=Sentinel2Bot

[Service]
WorkingDirectory=/root/sentinel-tg-bot
EnvironmentFile=/root/sentinel-tg-bot/.env
ExecStart=/root/sentinel-tg-bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target

```

Команды для обновления:
```bash
cd ~/sentinel-tg-bot
git pull
systemctl restart sentinel2bot
```
