# Sentinel-2 Telegram Bot 🌍🛰️

Бот для Telegram, который по названию места, координатам или файлу GeoJSON находит наименее облачный снимок Sentinel-2 L2A за указанный период, присылает его вместе с GeoTIFF и позволяет дешифрировать снимок прямо в чате: считать спектральные индексы, строить композиты, классифицировать и векторизовать.

**Бот в Telegram:** [@sentinel2_geo_bot](https://t.me/sentinel2_geo_bot)

## Возможности

**Поиск снимка**
- Ввод зоны: название места, адрес или координаты точки (геокодирование через OpenStreetMap Nominatim) либо файл GeoJSON с точкой, полигоном или мультиполигоном (до 20 МБ, берется первый объект файла).
- Интерактивный диалог: радиус зоны (0.1-50 км) и временной интервал.
- Выбор снимка в два этапа: из каталога берутся метаданные до 200 снимков и 5 лучших по облачности тайла, затем облачность пересчитывается по слою SCL (классы 8, 9, 10) только внутри зоны, и выбирается снимок с минимальным значением.
- Результат: фото-превью и GeoTIFF с геопривязкой (B04, B03, B02 и dataMask, float32). В подписи: адрес, охват, ID и дата снимка, облачность, разрешение и размер.
- Разрешение 10 м, для большой зоны 20 или 60 м, максимум 2500 пикселей по стороне. GeoTIFF больше 50 МБ не отправляется.
- Система координат: WGS84 (EPSG:4326). GeoJSON в другой системе координат перепроецируется автоматически.

**Обработка снимка** (кнопки под результатом)
- **Индексы:** NDVI, MNDWI, NDWI, NBR, NDBI. Картинка с фиксированной цветовой шкалой от -1 до 1 и GeoTIFF с одним каналом.
- **Композиты:** готовые наборы (Ложный ИК, SWIR, Сельхоз) и свой набор до 6 каналов (B01-B09, B8A, B11, B12, SCL). Картинка для 1-3 каналов, GeoTIFF со всеми выбранными каналами.
- **Классификация:** вода, застройка / открытый грунт, растительность, прочее. Пороговые правила по индексам и каналам, очистка шума, кнопки "больше / меньше" для подстройки порогов. Результат: карта с легендой и GeoTIFF с кодами классов (uint8).
- **Векторизация:** карта классов превращается в полигоны, результат отправляется файлом GeoPackage (.gpkg) с полями `class_type`, `class_name`, `area_km2`.

**Справка:** `/guide` (общая инструкция), `/indices`, `/composites`, `/class`, `/vector` (по разделам).

## Как это работает

1. Пользователь вводит локацию или отправляет GeoJSON.
2. Бот запрашивает радиус (для точки) и временной интервал (ГГГГ-ММ-ДД ГГГГ-ММ-ДД).
3. Локация преобразуется в геометрию в WGS84 (для точки и адреса: bbox с учетом широтной поправки).
4. Sentinel Hub Catalog API ищет снимки Sentinel-2 L2A в этой зоне и интервале (до 200 записей), оставляются 5 с наименьшей облачностью тайла.
5. Для каждого из 5 кандидатов запрашиваются SCL и dataMask с разрешением 60 м и считается доля облачных пикселей внутри зоны. Выбирается снимок с минимальной долей.
6. Sentinel Hub Process API запрашивает каналы B04, B03, B02 и dataMask выбранного снимка.
7. Бот отправляет превью и GeoTIFF. Снимок сохраняется в сессии пользователя.
8. Для индексов, композитов и классификации недостающие каналы докачиваются одним запросом при первом нажатии кнопки, дальше все считается локально из сессии.

## Технологии

- Python 3.12, окружение conda (conda-forge), запуск в Docker
- `sentinelhub` (v3.11.5) - Catalog API и Process API Sentinel Hub (Copernicus Data Space)
- `geopy` (v2.4.1) - геокодирование через Nominatim (OSM)
- `python-telegram-bot` (v22.8) - диалоговый интерфейс и инлайн-кнопки
- `rasterio` (v1.5.0), `shapely` (v2.1.2), `geopandas` (v1.2.0) - GeoTIFF, геометрии, векторизация, GeoPackage
- `numpy`, `scipy` - расчет индексов и классификации
- `matplotlib`, `Pillow` - картинки, шкалы и легенды
- `python-dotenv` (v1.2.4) - переменные окружения

Список зависимостей: `environment.yml`.

## Настройка

Создать файл `.env` в корне проекта и добавить ключи (значения без кавычек):
```env
BOT_TOKEN=ваш_токен_telegram
SH_CLIENT_ID=ваш_client_id_sentinel_hub
SH_CLIENT_SECRET=ваш_client_secret_sentinel_hub
```

## Запуск в Docker (рекомендуется)

Нужны установленные Docker и Docker Compose.

1. Клонировать репозиторий:
```bash
git clone https://github.com/xzbey/sentinel-tg-bot.git
cd sentinel-tg-bot
```

2. Создать `.env` (см. раздел "Настройка").

3. Собрать образ и запустить бота в фоне:
```bash
docker compose up -d --build
```

4. Посмотреть логи:
```bash
docker compose logs -f
```

Образ собирается на базе `mambaorg/micromamba`: зависимости ставятся из `environment.yml`, затем копируется код из `src/`. Пример `docker-compose.yml`:

```yaml
services:
  bot:
    build: .
    container_name: sentinel2bot
    restart: unless-stopped
    env_file: .env
```

## Запуск без Docker (conda)

```bash
conda env create -f environment.yml
conda activate tgbot-env
cd src
python bot.py
```

`.env` может лежать в корне проекта или в `src/`: `python-dotenv` ищет его рядом с `bot.py` и в папках выше.

## Развертывание на сервере

Проект работает на VPS (Ubuntu 24.04) в Docker. Порты открывать не нужно: бот сам обращается к Telegram (polling).

**Автозапуск.** Дополнительный сервис `systemd` не нужен:
- `restart: unless-stopped` в `docker-compose.yml` поднимает контейнер после сбоя и после перезагрузки сервера;
- служба Docker должна запускаться вместе с системой (`systemctl is-enabled docker`, при необходимости `systemctl enable docker`).

Если бот был остановлен вручную (`docker compose stop` или `down`), после перезагрузки он сам не запустится.

**Обновление:**
```bash
cd ~/sentinel-tg-bot
git pull
docker compose up -d --build
```

**Миграция со старого сервиса.** Если бот раньше работал через `systemd`, перед запуском контейнера остановить старый сервис, иначе два экземпляра с одним токеном будут конфликтовать:
```bash
systemctl disable --now sentinel2bot
```
